# AIToolsConnector

Discover the right AI tool for any job.

**Live:** https://theaitools.bolt.host/

## What it is

There are far too many AI tools and it is hard to know which one fits the task in front of you. AIToolsConnector is a discovery site that helps you find the right AI tool for the job you are trying to get done.

## Who it is for

Students, developers, creators and teams who want a faster way to find a suitable AI tool instead of searching through endless lists.

## Project notes

- Built and hosted on Bolt (`bolt.host`)
- Part of the Shipping Sandbox collection of shipped products
